# Maaltijdplanner

Plan maaltijden vanuit Home Assistant. Deze versie toont het overzicht en de huishoudinstellingen.

## Installatie

1. Voeg deze repository toe onder Instellingen, Apps, Installatiebronnen.
2. Installeer Maaltijdplanner.
3. Start de app.
4. Open de webinterface. Zet desgewenst de zijbalk aan. Die is zichtbaar voor alle gebruikers van Home Assistant.

## Gegevens

De database, foto's, back-ups, logs en sleutels staan in de gegevensmap van de app. Een update laat die map staan. Vóór een databasemigratie maakt de app een back-up.

## Wat er nog niet in zit

Recepten, het weekmenu, boodschappen, voorraad, AI en supermarkten komen in latere versies. Een diner plannen vanuit de Home Assistant-agenda hoort bij de custom integration, die apart wordt geïnstalleerd.
